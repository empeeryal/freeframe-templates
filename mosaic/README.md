# Mosaic

A colourful, cut-paper website template for a community arts centre, built with HTML, Tailwind CSS v4 and
vanilla JavaScript. The demo is Mosaic, an arts centre in an old dye works on Market Street, Ulverston.
Version 1.0.0.

## What's included

- Nine pages: home, what's on, event, workshops, hire a space, get involved, our story, visit and 404.
- A programme of classes, gigs, film nights, family sessions and exhibitions whose dates are worked out from
  rules ("every Tuesday", "first Sunday of the month"), so it is always current.
- Filters, saved events, calendar (.ics) downloads, a live room-hire estimate and validated demo forms.
- Original cut-paper SVG artwork and an illustrated map.

## Quick start

Open `index.html` in a browser, or serve the folder with any static server. Nothing needs installing.

To change the styles, install Node 24 and rebuild the CSS:

```sh
npm install
npm run build
```

Edit the programme, rooms and opening hours in `assets/js/data.js`. Read [DOCS.md](DOCS.md) for the full guide.
