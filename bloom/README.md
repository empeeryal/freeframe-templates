# Bloom: free HTML5 + Tailwind CSS salon and spa website template

A complete website for a hair salon and day spa, built for the fictional **Bloom Hair & Spa** in Bristol: a service menu, a team page with level-based pricing, a five-step booking wizard with real time slots from opening hours, staff rotas and treatment length, gift cards, and a gallery with saved looks. Plain HTML, Tailwind CSS v4 and one vanilla JavaScript file.

**Version 1.0.3** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/bloom)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes (Node.js 24):

```sh
npm install
npm run build
```
