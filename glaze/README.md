# Glaze — HTML + Tailwind CSS template

A shop website for **Vennick Clay**, a fictional pottery studio on Kirkgate in Otley, West Yorkshire: a home
page with a still life drawn in SVG, a shop of twelve stoneware pieces filtered by shape, glaze and “ready to
send”, product pages with glaze and size choices, stock and delivery dates, workshop booking with dates that
roll forward, a saved basket with delivery or free collection, a checkout with an order confirmation, the
studio story and glaze guide, care and delivery, a visit page with live opening hours and kiln-opening
Saturdays, and a 404 page. Every pot is drawn from the product data, so there are no photos to replace. Plain
HTML, Tailwind CSS v4 and vanilla JavaScript.

**Version 1.0.0** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/glaze)

## Quick start

Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

To change styles (Node.js 24 or newer):

```sh
npm install
npm run watch     # rebuilds assets/css/style.css while you edit
```
