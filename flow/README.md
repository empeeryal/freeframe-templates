# Flow: free HTML5 + Tailwind CSS yoga studio website template

A calm, airy website for an independent yoga studio, built for **Salt & Sage Yoga**, a fictional studio above the
harbour in Falmouth, Cornwall. Sand, clay, sage and sea tones, generous whitespace, hand-drawn line art, arch frames
and soft wave dividers, with EB Garamond headings and Mulish text. It shows today's classes on the home page,
has a rolling seven-day timetable with filters and now/next markers, lets visitors reserve a specific mat in the
room and keep track of it under My bookings, compares passes and memberships with an intro-offer calculator, and
includes workshops and retreats with a booking enquiry, a beginners' guide and a searchable FAQ. Plain HTML,
Tailwind CSS v4 and one vanilla JavaScript file.

**Version 1.0.0** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/flow)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes (Node.js 24):

```sh
npm install
npm run build
```
