# Steer: HTML5 + Tailwind CSS driving school website template

A clean, confident website for a driving school or driving instructor, built for the fictional **Brayline Driving School** in Lincoln: a week-view lesson booking with free times worked out from today, a pick-up postcode checker and district map, six instructors with their own cars and diaries, a price calculator with block, student and new-pupil discounts, a theory practice quiz with saved best scores, a pupil passes wall and a searchable FAQ. Plain HTML, Tailwind CSS v4 and one vanilla JavaScript file.

**Version 1.0.0** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/steer)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes (Node.js 24):

```sh
npm install
npm run build
```
