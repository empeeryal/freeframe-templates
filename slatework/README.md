# Slatework

A nine-page HTML5 and Tailwind CSS v4 website for Slatework, an applicant tracking system for companies with 50 to
1,000 employees, based in Lexington, Kentucky. Includes a live hiring pipeline board in the hero (drag and drop, or
a keyboard menu), a product tour with a job board picker, a weighted interview scorecard, a panel scheduler across
US time zones and an offer pay band check, per-employee pricing with a cost calculator, filterable customer
stories, a searchable integrations directory, a security and compliance page, resources with rolling monthly
webinars and a demo request form. Light and dark themes.

## Quick start

Open `index.html` in a browser, or serve this folder with `python3 -m http.server 8080`. Google Fonts need an
internet connection. No install or build is needed to view the site.

To rebuild the CSS after changing Tailwind classes (Node 24):

```sh
npm install
npm run build
```

See [DOCS.md](DOCS.md) for the content data, features, saved-state keys, date rules, form integration and
deployment.
