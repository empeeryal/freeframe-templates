# Solstice: festival and event template

A sunny, poster-style website for an outdoor food and music festival, made for the fictional
**Solstice 2027** in Leicester: a live countdown, a filterable line-up with artist pop-ups, a multi-stage
timetable with a personal plan, clash warnings and calendar export, tickets with early-bird prices and a
group discount, a food village with dietary filters and an interactive site map. Plain HTML, Tailwind CSS v4
and vanilla JavaScript.

**Version 1.0.0** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/solstice)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes:

```sh
npm install
npm run build
```
