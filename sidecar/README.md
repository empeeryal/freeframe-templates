# Sidecar

A ten-page HTML5 and Tailwind CSS v4 website for Sidecar, a 14-person product design and engineering studio in
Little Rock, Arkansas, that startups hire to design, build and launch their first product. Includes a work index
with service and stage filters and a grid or list layout, a full case study with a sketch-to-shipped compare
slider, services with a model helper, an engagement estimator with a price range and sample timeline, a 12-week
process with week tabs, a team page with drawn portraits, open roles with filters and a five-step project brief
with rolling start dates. A warm, light "build log" design with drawn artwork.

## Quick start

Open `index.html` in a browser, or serve this folder with `python3 -m http.server 8080`. Google Fonts need an
internet connection. No install or build is needed to view the site.

To rebuild the CSS after changing Tailwind classes (Node 24):

```sh
npm install
npm run build
```

See [DOCS.md](DOCS.md) for the content data, features, saved-state keys, date rules, form integration and
deployment.
