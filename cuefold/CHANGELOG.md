# Changelog

## [Unreleased]

## [1.0.1] - 2026-11-05

### Changed

- The guide, README and changelog use American spelling. The template itself is unchanged.

## [1.0.0] - 2026-10-20

### Added

- Ten HTML pages for an independent theater, with eighteen productions and a six-week program of thirty-six
  performances that roll forward only once they have happened.
- Program filters, a saved visit planner that keeps performances until they've happened, overlap checks, access
  preferences and a downloadable plan.
- Ticket and workshop requests that finish with a box-office reply and reference, and an arrival-time calculator.
- Original SVG production, workshop, people and venue artwork, Fahkwang and Questrial from Google Fonts, and
  complete documentation.
