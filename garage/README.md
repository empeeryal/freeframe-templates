# Garage: HTML5 + Tailwind CSS car repair and MOT garage website template

A bold, mechanical website for an independent car repair garage, MOT test centre or mechanic, built for the fictional **Bellcrank Motor Works** in Kidderminster: a fixed-price service checker, a booking request with UK number plate formatting and a drop-off calendar that skips Sundays and bank holidays, a courtesy car option, an MOT due-date calculator with saved reminders, filterable services, reviews and a searchable FAQ. Plain HTML, Tailwind CSS v4 and one vanilla JavaScript file.

**Version 1.0.0** · [Documentation](DOCS.md) · [Changelog](CHANGELOG.md) ·
[Live demo](https://freeframe.dev/templates/garage)

## Quick start

Open `index.html` in a browser. It works straight away: no install or build step is needed.

To rebuild the CSS after changing `src/input.css` or adding new Tailwind classes (Node.js 24):

```sh
npm install
npm run build
```
